📊 Sobre o Projeto

Este projeto tem como objetivo desenvolver um dashboard de vendas utilizando o Microsoft Excel, transformando dados brutos em informações visuais que facilitam a análise do desempenho de vendas e auxiliam na tomada de decisões.

O desafio faz parte dos estudos de análise de dados e tem como foco a organização, tratamento e visualização de informações.

🎯 Objetivo

Criar um dashboard interativo e visualmente organizado para analisar os dados de vendas do Xbox, permitindo identificar indicadores importantes e acompanhar o desempenho dos planos e suas respectivas assinaturas.

🛠️ Ferramentas Utilizadas
Microsoft Excel
Tabelas e gráficos dinâmicos
Indicadores de desempenho (KPIs)
Filtros visuais e segmentação de dados
Visualização e análise de dados
📁 Dados Utilizados

Foi utilizada a base de dados disponibilizada como material de apoio no desafio, contendo informações relacionadas às vendas e assinaturas dos planos.

Os dados foram organizados para possibilitar a construção dos indicadores e das visualizações presentes no dashboard.

📈 Desenvolvimento e Personalizações

Durante o desenvolvimento do projeto, foram trabalhados os seguintes conceitos:

Organização e análise da base de dados.
Transformação de dados em informações.
Criação de gráficos para visualização dos resultados.
Desenvolvimento de indicadores de desempenho (Big Numbers).
Utilização de filtros visuais para facilitar a análise.
Organização e estilização do dashboard.
🎨 Decisões de Design

Algumas alterações foram realizadas em relação à proposta original do exercício:

Idioma: todo o dashboard foi adaptado para o inglês, buscando manter a consistência visual e padronização dos elementos.
Identidade visual: foi adotada uma abordagem mais direta, limpa e orientada ao ambiente corporativo (business-oriented), priorizando a leitura rápida dos indicadores e a objetividade na apresentação das informações.
Visualização adicional: foi desenvolvido um gráfico específico para demonstrar a evolução do crescimento de assinantes e a popularidade dos diferentes planos, ampliando as possibilidades de análise da base de dados.
📌 Resultado

O resultado é um dashboard de vendas desenvolvido no Excel, com visualizações que facilitam a interpretação dos dados e permitem uma análise mais clara das informações.

Além de atender à proposta original do desafio, o projeto incorpora melhorias de apresentação visual e uma análise complementar da evolução dos planos e de sua base de assinantes.
